# Олег & Ксения — свадебное приглашение

Сайт-приглашение с конвертом, карточками во всплывающих окнах и анкетой гостя.

Живая страница: https://inchik3.github.io/oleg-ksenia-wedding/

## Куда вставить ссылку на Google Таблицу

**Не вставляйте обычную ссылку на таблицу** вида `https://docs.google.com/spreadsheets/...`

Нужна ссылка **веб-приложения Apps Script**. Она выглядит так:

`https://script.google.com/macros/s/AKfycb...../exec`

Вставьте её сюда:

`project/js/config.js` → поле `rsvp.googleAppsScriptUrl`

После сохранения закоммитьте и запушьте в `main` — GitHub Pages обновит сайт сам.

## Как один раз подключить таблицу

1. Создайте новую Google Таблицу.
2. Меню **Расширения → Apps Script**.
3. Удалите код по умолчанию и вставьте содержимое файла `apps-script/Code.gs`.
4. Нажмите дискету (сохранить).
5. **Развернуть → Новое развёртывание**.
6. Тип: **Веб-приложение**.
7. «Выполнять от имени»: **меня**.
8. «У кого есть доступ»: **все**.
9. Нажмите **Развернуть**, подтвердите доступ к таблице.
10. Скопируйте URL, который **заканчивается на `/exec`**.
11. Вставьте его в `project/js/config.js` в `googleAppsScriptUrl`.
12. Отправьте тестовую анкету с сайта и проверьте лист **RSVP**.

Если меняли код скрипта после публикации — снова **Развернуть → Управление развёртываниями → Изменить → Новая версия**.
